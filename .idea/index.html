How the code maps to the lesson

  1. Canvas: ctx paints each frame.
  2. Game loop: loop() calls update() then draw() via requestAnimationFrame.
  3. Input: the keys object records held keys; pointer dragging sets a target.
  4. State: player, sparks, blocks, and score hold everything.
  5. Collisions: hit(a, b) is a rectangle overlap check.
  6. Next steps: add sound, sprites, levels, or a power-up.
